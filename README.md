# ATP007 — Certified Kubernetes Security Specialist (CKS)

Preparation scaffold: one stage per exam domain, connected through `path.yaml`
to a training series repository. New material is planned, and the course
registration in `astrona-content` stays **draft**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Cluster Setup | 15% | [ATS031](https://github.com/astrona-io/ATS031) |
| STG002 | Cluster Hardening | 15% | [ATS032](https://github.com/astrona-io/ATS032) |
| STG003 | System Hardening | 10% | [ATS033](https://github.com/astrona-io/ATS033) |
| STG004 | Minimize Microservice Vulnerabilities | 20% | [ATS034](https://github.com/astrona-io/ATS034) |
| STG005 | Supply Chain Security | 20% | [ATS035](https://github.com/astrona-io/ATS035) |
| STG006 | Monitoring, Logging and Runtime Security | 20% | [ATS036](https://github.com/astrona-io/ATS036) |
